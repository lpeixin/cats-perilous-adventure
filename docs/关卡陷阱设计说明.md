## 一、先讲设计原则

这份文档记录的是"坑埋在哪"，但比坐标更重要的是**为什么埋在那**。

### 1. 第一次遇到，基本躲不掉

这是这类游戏的核心体验：**第一次踩坑必须死**，靠死亡来教学。
所以每个陷阱的第一次出现都放在"看起来最安全"的地方，而且几乎没有预警：

- 碎裂地板和真草地**像素级一致**（同一份绘制代码，连噪点位置都一样）
- 传送带和石块**用的是同一张贴图**
- 伪装太阳 / 云和真正的装饰云**只差一点点色温**，而且混在真云里
- 隐形砖块干脆完全透明

### 2. 但第二次必须能过

"阴"和"不讲理"是两回事。所以每个陷阱都有一个**很短的、但确实存在的**预警窗口：

| 陷阱 | 预警窗口 | 参数（`src/utils/constants.js`） |
| --- | --- | --- |
| 地板消失 | 踩上后抖动 0.3 秒才塌 | `CRUMBLE_DELAY_MS: 300` |
| 隐藏传送带 | 站上后静止 0.34 秒才开始下沉 | `CONVEYOR_DELAY_MS: 340` |
| 天空掉落物 | 掉落前抖动约 0.11 秒 | `trigger()` 里的 55ms × 2 次 |
| 水管伏兵 | 猫进入 210px 内才弹出 | `PIPE_AMBUSH_RANGE: 210` |
| 假通关 | 假装过关 0.9 秒后才抽地板 | `FAKE_GOAL_FAKE_MS: 900` |
| 蘑菇陷阱怪 | 猫进入 300px 才扑咬 | `FAKE_ITEM_RANGE: 300` |

想让某一关更狠 / 更仁慈，**改这些数字就行，全关卡一起生效**，
不需要去动关卡数据。

### 3. 前 30% 稀疏教学，后 70% 密集组合

以第一关为例：

- 第 0–60 格（前 30%）：隐形墙 → 隐形砖 → 真问号砖 → 假道具砖 → 碎裂地板。
  **每类陷阱只出现一次**，而且彼此隔得很开，死一次就能记住。
- 第 60 格之后：开始**组合**。比如"水管伏兵 + 跨坑跳跃"、
  "伪装太阳 + 隐形砖正好卡在跳跃路径上"、"传送带平台 + 终点前再来一发伪装太阳"。

第三关则是把组合玩到极致：碎裂地板 40 块、伪装太阳 5 个、水管伏兵 3 处，
一进关就是连续两块伪装草地（第 19–23 格、第 39–45 格）。

### 4. 每一关都有一个"终极整活"

关卡结尾一定要留一个最有记忆点的坑：

- **第一关**：假通关旗杆（第 163 格）之后，真终点前还埋了一发伪装太阳（第 182 格）
  —— 你以为识破了假旗杆就赢了，临门一脚再送你一下。
- **第二关**：真终点前（第 202 格）放了一根隐形砖（第 183 格）和鱼罐头，
  最后一个坑紧贴着终点。
- **第三关**：假旗杆在第 178 格，之后还有一段碎裂地板桥（165–171 格已经在前面了）、
  隐形砖（第 196 格）和一发伪装太阳（第 190 格），真终点在第 213 格。

## 二、七类陷阱是怎么实现的

全部在 `src/entities/Trap.js` 里，**每一类都是可复用组件**，
关卡数据里只写一个字符，`LevelScene` 负责把字符实例化成组件。
想加第八种陷阱，只要：加字符 → 加组件类 → 在 `LevelScene.buildTiles/buildEntities` 里认领。

| # | 陷阱 | 组件类 | 关卡字符 | 关键行为 |
| --- | --- | --- | --- | --- |
| 1 | 隐形砖块 | `InvisibleBlock` | `H` | 初始 `alpha = 0`；被顶到才现形（Back 缓动放大 + "！"提示） |
| 2 | 伪装天空掉落物 | `SkyDropper` | `v` / `o` | 触发前 `body.enable = false`，纯装饰；触发后加速下落，砸到地面碎裂消散，砸到猫即死 |
| 3 | 假道具真陷阱 | `MushroomTrap`（`Enemy.js`） | `!` | 顶出来的是蘑菇怪，冒头动画结束后立刻朝猫扑咬 |
| 4 | 水管伏兵 | `PipeAmbush` | `A` | 猫进入 210px → 从管口弹出毛线球（`vy = -780`），落点几乎贴着玩家 |
| 5 | 地板消失 | `CrumbleTile` | `*` | 抖动 0.3 秒 → 换帧 → 塌陷；地表版本贴图 = `crumble_ground`（与真草地一致） |
| 6 | 假通关旗杆 | `GoalPole`（`isFake`） | `F` | 播放"过关"音效 + 冻结玩家 0.9 秒 → 抽掉旗杆周围 4 格地板 → 旗杆歪倒沉没 |
| 7 | 隐藏向下传送带 | `ConveyorTile` | `>` | 外观 = `stone`；静止 0.34 秒后带着玩家一起下沉 5 格，然后整块消失 |

另外还有两个**纯干扰项**，不杀人但极其重要 —— 它们是"狼来了"里的羊：

- `.` **无害云**：和伪装云长得几乎一样，飘在天上永远不动手
- `S` **石块平台**：和传送带长得一模一样，踩上去什么都不会发生

第一关有 **6 朵无害云**、第二关 4 朵、第三关 1 朵。玩家被伪装云砸过之后，
会对所有云产生警惕；而大量无害云的存在，会让这份警惕一直保持下去。

## 三、难度曲线建议

如果后续要加第四关，建议按这个节奏：

1. **开场 30 格**：不要放任何陷阱，让玩家先跑起来、建立"这是普通平台跳跃"的错觉
2. **第一个坑**：用**不致死**的隐形墙（`H` 放在地表那一行）当"友善的提醒"
3. **第二、三个坑**：教一类致死陷阱，只放一次，周围留足空间
4. **中段**：开始两两组合（碎裂地板 + 水管伏兵、伪装太阳 + 隐形砖）
5. **后段**：三种以上叠加，并且压缩反应时间（把 `PIPE_AMBUSH_RANGE` 调小一点）
6. **结尾**：假旗杆 + 一个"以为识破了但其实还有"的补刀

### 加关卡的三种方式

**方式一：直接手改 ASCII**（最快，适合微调）

打开 `src/levels/level1.json`，`rows` 就是一张能直接看懂的地图，
把某个字符换成另一个即可。字符表见 `src/utils/constants.js` 的 `LEGEND`。

**方式二：用 Python DSL 生成**（适合重做一整关）

```python
# tools/build_levels.py
def level4():
    L = Level(210, name="第四关 · 深夜的院子", subtitle="这次连月亮都会砸人")
    L.ground(0, 30); L.ground(36, 70)
    L.crumble_bridge(31, 35)          # 跨坑的伪装草地
    L.invisible(48, 10)               # 卡在跳跃路径上的隐形砖
    L.pipe(60, 10, 2); L.ambush(60, 10)
    L.evil_sun(80, 2)                 # 伪装成背景的太阳
    L.fake_goal(150)                  # 假通关
    L.real_goal(190)                  # 真终点（必须在假旗杆右边）
    return L
```

然后 `npm run gen:levels && npm run validate`。

**方式三：只调难度，不动布局**

改 `src/utils/constants.js` 的 `TRAP` 段。比如想让传送带更阴，
把 `CONVEYOR_DELAY_MS` 从 340 调到 200；想让土狼时间更宽容，
把 `PHYS.COYOTE_MS` 从 100 调到 150。

## 四、校验与自检

改完关卡务必跑一遍：

```bash
npm run validate   # 字符合法性、陷阱种类 ≥3、真旗杆唯一且在假旗杆右侧、
                   # 出生点脚下有地面、水管成对、伏兵标记依附在管道上……
npm run smoke      # 无头浏览器把游戏真跑一遍，65 项断言（需要先 npm run dev）
npm run traps      # 刷新本文档里的陷阱清单
```

`npm run validate` 会给出两类提示：

- `⚠ 隐形砖块 (x,y) 与地表同高，会变成"隐形墙"` —— 这是**允许**的设计
  （第一关第 27 格那个就是故意的"友善提醒"），确认是你想要的即可。
- 若出现"陷阱种类不足 3 种""找不到真终点""出生点悬空"之类的**报错**，就必须修。

## 五、一句话总结

> 埋坑的关键不是"多"，而是**节奏**：
> 让玩家在"我懂了"和"我又被骗了"之间反复横跳。
> 死一次要觉得好笑，而不是觉得被欺负。
